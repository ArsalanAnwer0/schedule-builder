# Troubleshooting

Solutions to common issues and problems with Schedule Builder. If you don't find your issue here, check the [FAQ](/faq) or [contact support](/legal/contact).

## Login and Authentication Issues

### Can't Log In

**Problem:** Unable to log in with your credentials.

**Solutions:**
1. Verify your email address is correct
2. Check that Caps Lock is off when entering password
3. Ensure you're using the correct password
4. Try the "Forgot Password" feature if needed
5. Clear browser cache and cookies
6. Try a different browser

### Forgot Password

**Problem:** Need to reset your password.

**Solution:**
1. Click "Forgot Password" on the login page
2. Enter your email address and new password
3. Submit the request
4. Wait for admin approval (for students)
5. You'll receive an email when approved
6. Log in with your new password

**Note:** Primary and Secondary Admins can reset passwords immediately. Students require admin approval.

### Email Verification Issues

**Problem:** Haven't received verification email.

**Solutions:**
1. Check spam/junk folder
2. Verify email address is correct in your profile
3. Request a new verification email
4. Wait 5-10 minutes for delivery
5. Contact support if issue persists

## Scheduling Issues

### Can't Submit Availability

**Problem:** Unable to submit availability when requested.

**Solutions:**
1. Verify you're logged in
2. Check that the request is still open
3. Ensure all required fields are completed
4. Try refreshing the page
5. Clear browser cache
6. Use a different browser

### Schedule Not Visible

**Problem:** Can't see published schedule.

**Solutions:**
1. Verify the schedule has been published
2. Check that you're assigned to the schedule
3. Refresh the page
4. Check notification settings
5. Verify your account is active
6. Contact your admin

### Can't Generate Schedule

**Problem:** Schedule generation fails or produces errors.

**Solutions:**
1. Verify all availability submissions are complete
2. Check for conflicting requirements
3. Review scheduling rules
4. Ensure adequate coverage is possible
5. Try adjusting date range
6. Contact support if issue persists

## Notification Issues

### Not Receiving Emails

**Problem:** Missing email notifications.

**Solutions:**
1. Check spam/junk folder
2. Verify email address in profile
3. Check notification preferences
4. Ensure emails aren't being blocked
5. Add noreply@schedule-builder.xyz to contacts
6. Contact support to verify email status

### Missing In-App Notifications

**Problem:** Not seeing in-app notifications.

**Solutions:**
1. Refresh the page
2. Check notification bell icon
3. Verify notification settings
4. Clear browser cache
5. Try logging out and back in

## Performance Issues

### Slow Loading

**Problem:** Pages load slowly or time out.

**Solutions:**
1. Check your internet connection
2. Clear browser cache and cookies
3. Disable browser extensions temporarily
4. Try a different browser
5. Check system status page
6. Contact support if widespread

### Browser Compatibility

**Problem:** Features not working properly.

**Recommended Browsers:**
- Chrome (latest version)
- Firefox (latest version)
- Safari (latest version)
- Edge (latest version)

**Solutions:**
1. Update to latest browser version
2. Enable JavaScript
3. Allow cookies
4. Disable conflicting extensions
5. Try incognito/private mode

## Data and Display Issues

### Information Not Updating

**Problem:** Changes not reflected immediately.

**Solutions:**
1. Refresh the page (F5 or Cmd+R)
2. Hard refresh (Ctrl+F5 or Cmd+Shift+R)
3. Clear browser cache
4. Wait a few minutes for sync
5. Log out and log back in

### Missing Data

**Problem:** Expected data is not showing.

**Solutions:**
1. Verify you have correct permissions
2. Check that data was saved properly
3. Refresh the page
4. Verify date range filters
5. Contact support to verify data

## Error Messages

### "Session Expired"

**Solution:**
1. Log out completely
2. Clear browser cookies
3. Log back in
4. Save work frequently to avoid data loss

### "Permission Denied"

**Solution:**
1. Verify your user role
2. Check if action requires admin privileges
3. Contact your Primary Admin
4. Ensure account is active

### "Invalid Token"

**Solution:**
1. Request a new password reset
2. Use the latest link from email
3. Don't use expired links (valid for 1 hour)
4. Contact support if issue continues

## Account Issues

### Can't Update Profile

**Problem:** Unable to save profile changes.

**Solutions:**
1. Verify all required fields are completed
2. Check password meets requirements
3. Ensure email isn't already in use
4. Try refreshing the page
5. Contact support if issue persists

### Removed from Organization

**Problem:** No longer have access.

**Solution:**
1. Verify with your administrator
2. Check email for notifications
3. Request to be re-invited if appropriate
4. Contact support if this was in error

## Mobile App Issues

### Mobile Site Not Working

**Problem:** Issues accessing on mobile device.

**Solutions:**
1. Use mobile browser (Safari, Chrome)
2. Ensure JavaScript is enabled
3. Clear mobile browser cache
4. Try desktop mode if needed
5. Update mobile browser

### Display Issues on Mobile

**Problem:** Layout problems on phone/tablet.

**Solutions:**
1. Rotate device (portrait/landscape)
2. Zoom out if needed
3. Try different browser
4. Clear cache
5. Report issue to support
