# Creating Schedules

Learn how to create, optimize, and manage schedules effectively using Schedule Builder.

## Schedule Creation Process

### Step 1: Request Availability

Before creating a schedule, you need to collect availability from your team:

1. Navigate to the dashboard
2. Click "Request Availability"
3. Configure the request:
   - Set the date range
   - Add any special instructions
   - Review team member list
4. Send the request

Team members will receive an email notification and can submit their available time slots through the platform.

### Step 2: Review Submissions

Once team members submit their availability:

1. Navigate to the Availability section
2. Review all submissions:
   - Check submission status
   - Identify any conflicts
   - Note special requests
3. Follow up with team members who haven't submitted

::: tip
You'll receive a notification when all team members have submitted their availability.
:::

### Step 3: Generate Schedule

With availability collected, you can generate an optimized schedule:

1. Navigate to the Schedule section
2. Click "Generate Schedule"
3. The system will:
   - Analyze all availability data
   - Apply scheduling rules
   - Optimize for coverage and fairness
   - Generate a draft schedule

### Step 4: Review and Adjust

Review the generated schedule:

1. Check for any gaps in coverage
2. Verify fair distribution of shifts
3. Make manual adjustments if needed:
   - Drag and drop to reassign shifts
   - Add or remove time slots
   - Adjust shift durations
4. Save your changes

### Step 5: Publish Schedule

When satisfied with the schedule:

1. Click "Publish Schedule"
2. Add any notes or announcements
3. Confirm publication
4. Team members automatically receive notifications

## Schedule Management

### Editing Published Schedules

You can modify published schedules at any time:

1. Navigate to the published schedule
2. Click "Edit Schedule"
3. Make necessary changes
4. Save updates
5. Affected team members receive automatic notifications

### Copying Schedules

Save time by copying existing schedules:

1. Open the schedule you want to copy
2. Click "Copy Schedule"
3. Select the new date range
4. Adjust as needed
5. Publish the new schedule

### Exporting Schedules

Export schedules in various formats:

1. Open the schedule
2. Click "Export"
3. Choose format:
   - PDF for printing
   - CSV for spreadsheets
   - iCal for calendars
4. Download the file

## Scheduling Features

### Availability Patterns

The system recognizes common availability patterns:
- Recurring weekly availability
- One-time special requests
- Block-out dates
- Preferred time slots

### Conflict Detection

Automatic conflict detection prevents:
- Double-booking team members
- Scheduling during unavailable times
- Exceeding maximum hours
- Violating minimum rest periods

### Fair Distribution

The schedule generator ensures:
- Equitable shift distribution
- Balanced workload across team
- Consideration of preferences
- Coverage of all required slots

## Tips for Effective Scheduling

### Before Generating
1. Ensure all availability is submitted
2. Review any special requests
3. Check for holidays or special dates
4. Verify coverage requirements

### During Review
1. Look for potential issues
2. Consider team preferences
3. Balance workload fairly
4. Maintain adequate coverage

### After Publishing
1. Monitor for change requests
2. Address issues promptly
3. Keep documentation updated
4. Gather feedback from team

## Common Scenarios

### Handling Last-Minute Changes
1. Edit the published schedule
2. Update affected shifts
3. Notify team members immediately
4. Document the change

### Managing High-Demand Periods
1. Request availability early
2. Identify coverage needs
3. Consider temporary staff
4. Communicate expectations

### Dealing with Call-Offs
1. Note the absence in the system
2. Find replacement coverage
3. Update schedule
4. Notify affected parties

## Troubleshooting

### No One Available for Slot
- Review availability submissions
- Check for data entry errors
- Consider adjusting requirements
- Reach out to team for flexibility

### Schedule Won't Generate
- Verify all data is submitted
- Check for system conflicts
- Review scheduling rules
- Contact support if issue persists

### Team Member Can't See Schedule
- Confirm schedule is published
- Verify user permissions
- Check notification settings
- Ensure user is logged in
