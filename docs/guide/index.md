# User Guide

Complete guide to using Schedule Builder effectively. This section covers all features and functionality.

## Overview

Schedule Builder provides a comprehensive platform for team scheduling and workforce management. This guide will help you master all features.

## Main Features

### Schedule Management
- Create and edit schedules
- Request availability from team members
- Generate optimized schedules automatically
- Publish and distribute schedules
- Export schedules in multiple formats

### Team Administration
- Manage students and team members
- Invite and remove users
- Assign roles and permissions
- Track team availability

### Notifications System
- Email notifications for schedule changes
- In-app notifications
- Availability request alerts
- Password reset notifications

### User Roles

**Primary Admin**
- Full system access
- Can invite and manage secondary admins
- Approve password reset requests
- Manage all students and schedules

**Secondary Admin**
- Create and manage schedules
- Invite and manage students
- View reports and analytics
- Cannot manage other admins

**Student**
- Submit availability
- View assigned schedules
- Update profile information
- Request password resets

## Best Practices

### Schedule Creation
1. Request availability well in advance
2. Review all submissions before generating
3. Make manual adjustments as needed
4. Publish schedules with sufficient notice

### Team Management
1. Keep team information up to date
2. Remove inactive users promptly
3. Use appropriate roles for each team member
4. Monitor team availability regularly

### Communication
1. Enable email notifications
2. Check in-app notifications regularly
3. Communicate schedule changes promptly
4. Provide advance notice for changes

## Common Workflows

### Creating a Weekly Schedule
1. Request availability 1 week in advance
2. Wait for student submissions
3. Generate schedule
4. Review and adjust
5. Publish to team

### Managing Schedule Changes
1. Make necessary edits to published schedule
2. System automatically notifies affected team members
3. Confirm changes with team
4. Update schedule documentation

### Onboarding New Team Members
1. Invite user with appropriate role
2. User receives email invitation
3. User sets password and completes profile
4. Admin verifies user information
5. User gains access to system
